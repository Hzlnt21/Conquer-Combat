# Conquer Combat Credits

## Direction

- Creator, director, game concept, lore, and art direction: Hzlnt21
- Design, engineering, writing, and production collaboration: OpenAI Codex

## Technology

- Engine: Godot Engine 4.6
- Language: GDScript
- Renderer: Godot Compatibility renderer

## Visual Production

All shipped character and environment artwork is original to this project. Concepts were directed and approved by Hzlnt21. Runtime illustrations were created with OpenAI image generation from those approved references, then versioned, integrated, and visually verified in Godot.

No character art, stage art, UI, audio, or code from Street Fighter, Tekken, Naruto, Kamen Rider, or another commercial game or franchise is distributed with this project.

## Audio

Combat and UI sounds are original procedural PCM synthesis generated at runtime by `AudioDirector`.
